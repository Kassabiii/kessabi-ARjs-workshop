Do You Know Your Playlist?

A guessing game played on your own Spotify playlist. You hear a 0.1 second clip of a song and name it. Every wrong guess or skip makes the clip longer, and every second costs you points.

What you need

  • Spotify PremiumSpotify only lets Premium accounts play music in the browser.
  • A computerChrome, Edge or Firefox. Phone browsers can’t run the Spotify player.
  • Node.js 20+To run it on your machine. Free from nodejs.org.

How to play

  1. Connect Spotify

    and allow access to your playlists.

  2. Pick a playlist

    and how many songs to play: 5, 10 or 20.

  3. Listen

    Press ▶ or Space. You hear the very start of a random song from that playlist.

    0.1s0.5s1s2s4s8s
  4. Guess

    Type a title or artist, then pick the song with ↑ ↓ and Enter.

    • Right: points, from 100 at 0.1 s down to 10 at 8 s.
    • Wrong or Skip: the next, longer clip plays straight away.
    • Still stuck after 8 s: the answer is revealed.
  5. Enjoy the song

    Play, pause or resume the full track, then move on to the next one.

  6. See your score

    and every answer at the end. Play again or try another playlist.

Run it on your computer

  1. Unzip

    the download and open a terminal in the do-you-know-your-playlist folder.

  2. Create a Spotify app

    In the Spotify Developer Dashboard, click Create app:

    • Redirect URI: http://127.0.0.1:5173
    • Tick Web API and Web Playback SDK, then save.
    • Copy the Client ID from Settings.
    • Under User Management, add the Spotify accounts that will play.
  3. Add your Client ID

    Copy .env.example to a new file .env.local and paste the ID after VITE_SPOTIFY_CLIENT_ID=. You never need the Client secret.

  4. Install and start 
    npm install
npm run dev
  5. Open http://127.0.0.1:5173

    Use this exact address: Spotify rejects localhost.

The README.md inside the zip has the same steps, plus how to put it online with Netlify and a troubleshooting table.

Under the hood

  • Clips accurate to a tenth of a secondEach song is loaded muted and parked at 0:00, so a clip is a local play/pause in the browser rather than a slow network call.
  • No server, no stored dataSpotify login uses PKCE entirely in the browser; tokens live only for the session.
  • Fair guessingSuggestions come only from the chosen playlist, songs never repeat, and a remaster or live version of the right song counts.
